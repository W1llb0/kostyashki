# Костяшки

Дуэль на кубиках для браузера. Вся игра — один файл `index.html`, без сервера и сборки.

## Правила
1. У каждого игрока поле 3×3. В свой ход бросаете кубик и ставите его в любую свою колонку, где есть место.
2. Одинаковые кубики в колонке складываются и умножаются на их количество: `5,5` → 20, `3,3,3` → 27, `4,4,2` → 18.
3. Ваш кубик сжигает все кубики того же значения в колонке соперника напротив.
4. Партия кончается, когда у кого-то заполнены все 9 ячеек. Больше очков — победа.

## Режимы
- **Поход** — рогалик: 5 соперников подряд (последний — босс Хозяин Костей). В начале и после каждой победы выбираете 1 из 3 случайных даров. Соперники играют героями и тоже получают дары. 2 сердца: поражение отнимает одно, ничья — переигровка.
- **Против ИИ** — одна партия против компьютера (лёгкий / средний / сложный); у вас и у ИИ — герои.
- **Вдвоём** — классика на одном устройстве, без героев и даров.
- **Онлайн** — дуэль с другом в разных браузерах. Один создаёт комнату и отправляет ссылку (`…/?room=КОД`) или код, второй подключается. Правила: «Герои и дары» (каждый играет своим героем и выбирает 2 дара) или «Классика». После партии — реванш.

Героя и дары любого игрока можно посмотреть, нажав на его медальон или значки даров.

| Герой | Способность |
|---|---|
| Кузнец Горан | **Наковальня** — три одинаковых кубика в колонке дают ещё +12 |
| Ведьма Мора | **Порча** — за каждый сожжённый вами кубик соперник теряет ещё 3 очка |
| Монах Ильм | **Смирение** — ваши единицы нельзя сжечь, каждая даёт +4 |
| Шулер Лис | **Подмена** — раз за партию превратить свой кубик в 6 (клавиша S) |
| Стражница Вера | **Бастион** — средняя колонка под бронёй, каждый отражённый удар +5 |
| Пиромант Аш | **Пожар** — ваши шестёрки сжигают шестёрки во всех колонках соперника |
| Хозяин Костей (босс) | **Твердыня** — кубики в его заполненных колонках не горят |

### Как устроен онлайн без сервера
Ходы передаются через бесплатный публичный MQTT-брокер по защищённому WebSocket (библиотека [MQTT.js](https://github.com/mqttjs/MQTT.js), лежит в `vendor/`, лицензия MIT): broker.hivemq.com, а если он недоступен — broker.emqx.io или test.mosquitto.org. Первая буква кода комнаты указывает брокер. Подключение работает из любой сети, свой сервер не нужен.

Хозяин комнаты бросает кубики и проверяет ходы гостя. Сообщения пронумерованы и пересылаются, пока не придёт подтверждение. Некоторые провайдеры (например, в России для зарубежных хостингов) «замораживают» соединение после ~15–20 КБ данных — поэтому игра сама открывает новое соединение задолго до этого лимита и сразу переподключается, если соперник замолчал. Короткие обрывы связи ходы не теряют.

Ограничения: публичные брокеры бесплатные и без гарантий; сообщения в них не шифруются end-to-end (для игры в кости это не критично).

|---|---|---|
| 🌞 | Солнечная шестёрка | каждая 6 даёт +3 |
| 🪙 | Медяки | каждая 1 и 2 даёт +2 |
| ⚖️ | Чётный счёт | каждый чётный кубик +1 |

| 🌈 | Радуга | колонка из трёх разных значений +8 |
| 🗿 | Опора | средняя колонка ×1,5 |
| 🛡️ | Броня | первое сжигание в каждой колонке блокируется |
| ⚓ | Якорь | ваши шестёрки не сгорают |
| 🔥 | Угли | +3 за каждый сожжённый кубик соперника |
| 🎲 | Утяжелённая кость | никогда не выпадает 1 |
| 🏁 | Фора | +6 очков в начале партии |
| ⚡ | Инициатива | вы всегда ходите первым |
| 🔄 | Переброс | 2 переброса за партию (клавиша R) |
| 🙃 | Перевёртыш | 1 раз за партию перевернуть кубик (клавиша F) |
| ❤️ | Запасное сердце | +1 сердце |

Прогресс похода, рекорды и статистика хранятся в `localStorage` браузера — бэкенд не нужен.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub и загрузите в него `index.html` (и этот README).
2. Repository → **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
4. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Локальный запуск
Достаточно открыть `index.html` в браузере. Или:

```bash
python3 -m http.server 8000
```
